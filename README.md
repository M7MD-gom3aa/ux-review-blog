## 📌 About The Project

**The UX Review** is a front-end practice project that recreates a modern blog landing page from scratch using pure HTML5 and CSS3.

The design follows a bold **Neo-Brutalist** aesthetic, featuring thick black borders, hard offset shadows, vibrant colors, and heavy uppercase typography.

The project was built without frameworks, external libraries, or JavaScript.

## ✨ Features

- **Neo-Brutalist Design:** Bold borders, hard shadows, and vibrant flat colors.
- **Fixed Navigation Bar:** Rounded floating navbar with smooth in-page navigation.
- **Responsive Layout:** Adapts to desktop, tablet, and mobile screens.
- **Smooth Scrolling:** CSS-powered navigation between sections.
- **Interactive Hover Effects:** Buttons, cards, headlines, and social icons.
- **Sticky Sidebar:** Trending articles and categories follow the reader while scrolling.
- **Decorative Badges:** Rotated labels using CSS positioning and transforms.
- **Equal-Height Columns:** Balanced layout in the community section.
- **Pure HTML & CSS:** No frameworks, libraries, or JavaScript.

## 🖥️ Page Sections

| Section | Description |
|---|---|
| **Navigation** | Fixed navbar with logo, navigation links, and Subscribe button. |
| **Hero** | Bold headline, introduction, CTA buttons, and featured image. |

## 🛠️ Built With

- **HTML5** – Semantic structure and page sections.
- **CSS3**
  - Flexbox
  - CSS Nesting
  - Positioning (`fixed`, `sticky`, `absolute`)
  - Transforms & Transitions
  - Media Queries
  - `calc()` and `fit-content`
  - `oklch()` color values
- **Google Fonts** – Exo 2.

## 📱 Responsive Design

The project uses a desktop-first approach with five responsive breakpoints.

| Breakpoint | Description |
|---|---|
| `1400px` | Adjusts author role badges. |
| `1200px` | Resizes hero typography and repositions featured badges. |
| `992px` | Stacks hero, articles, sidebar, community, and footer layouts. |
| `768px` | Hides navigation links and converts article and author layouts. |
| `480px` | Fine-tunes typography, spacing, and component sizes. |
